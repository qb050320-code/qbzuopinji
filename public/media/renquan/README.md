# 《人圈》调色静帧

本目录 28 张图片均来自用户提供的《人圈》项目真实调色资料，原始资料目录为 `调色作品集/长片/人圈静帧/`。其中 01–24 为单张影片静帧，25–28 为 DaVinci Resolve 多镜头缩略图概览截图，应与影片单帧区分标注。

- `frame-01.webp` 至 `frame-28.webp`：按原始文件名顺序排列，长边最大 1920px，质量 90。
- `thumb-01.webp` 至 `thumb-28.webp`：长边最大 480px 的预览缩略图。
- `manifest.json`：站点使用路径、尺寸与原始文件名映射。

仅进行 EXIF 方向校正、等比缩小与 WebP 编码；没有裁切、改变饱和度、对比度或重新调色。原始 ICC 色彩配置存在时予以保留。站点大图应完整显示原始画幅，不应叠加色彩滤镜。
